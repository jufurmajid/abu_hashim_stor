# أبو هاشم للحوم والألبان والأجبان

موقع متجر ثابت وخفيف، مصمم حتى يبقى بسيط وسهل الصيانة على المدى الطويل.

## البنية

- **الموقع:** ملفات Static داخل المستودع.
- **المنتجات:** `data/products.json`.
- **إعدادات Telegram:** `data/store.json`.
- **بوت الإدارة:** `bot-worker/` ويعدّل المنتجات مباشرة في GitHub.
- **الطلبات:** الموقع يجهز الطلب ويفتح Telegram للزبون حتى يضغط إرسال.
- **قاعدة البيانات:** لا توجد قاعدة بيانات للموقع، لتقليل الأعطال والتكاليف.

## إدارة المنتجات

الحقول:
- `id`
- `n` اسم المنتج
- `p` السعر بالدينار العراقي
- `c` التصنيف
- `e` الإيموجي
- `active` إذا كانت `false` يختفي المنتج من الموقع.

يمكن إدارة المنتجات من بوت الإدارة:
- `/add`
- `/edit`
- `/hide`
- `/show`
- `/delete`
- `/list`

كل تعديل من البوت يصبح Commit في GitHub، وبعد تحديث الكاش تظهر النسخة الجديدة للموقع.

## تشغيل الموقع

المشروع مناسب للاستضافة الثابتة مثل GitHub Pages؛ لا يحتاج Node.js أو قاعدة بيانات لتشغيل المتجر نفسه.

## بوت الإدارة

تفاصيل إعداد البوت والأسرار موجودة في:
`bot-worker/README.md`

لا تضع Telegram Bot Token أو GitHub Token داخل ملفات الموقع.

## الاعتمادية

التصميم يتجنب ربط المتجر بقاعدة بيانات أو سيرفر دائم. إذا احتاج المتجر لاحقاً ميزات أكبر، يمكن إضافة Backend بدون تغيير واجهة المتجر الأساسية.
