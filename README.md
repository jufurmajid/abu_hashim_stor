# أبو هاشم للحوم والألبان والأجبان

متجر إلكتروني عربي بسيط ومتجاوب، مع بوت إدارة وبوت استقبال طلبات داخل نفس المشروع.

## المزايا
- عرض المنتجات والتصنيفات والبحث
- سلة مشتريات وطلب كضيف
- إرسال الطلب إلى تيليجرام
- أزرار قبول ورفض وتجهيز الطلب مباشرة من تيليجرام
- حفظ الطلبات محلياً مع رقم طلب
- بوت إدارة لإضافة وتعديل وإخفاء وحذف المنتجات
- فحص صحة السيرفر عبر `/api/health`
- عربي RTL ومتوافق مع الموبايل
- حقوق التطوير: جعفر ماجد

## التشغيل
```bash
npm install
cp .env.example .env
npm start
```
ثم افتح `http://localhost:3000`.

## أوامر بوت الإدارة
`/start`
`/products`
`/orders`
`/add الاسم | السعر | التصنيف | الإيموجي`
`/edit ID | الاسم | السعر | التصنيف | الإيموجي`
`/hide ID`
`/show ID`
`/delete ID`

## الإعداد
ضع `ADMIN_BOT_TOKEN` و`ORDERS_BOT_TOKEN` و`ADMIN_CHAT_ID` ويفضل `ORDERS_CHAT_ID` في `.env`.

لا تضع التوكنات داخل ملفات الواجهة أو المستودع العام.
