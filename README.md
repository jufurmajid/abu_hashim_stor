# أبو هاشم للحوم والألبان والأجبان

موقع متجر ثابت وخفيف.

## إدارة المنتجات
المنتجات موجودة في:
`data/products.json`

لإضافة أو تعديل أو إخفاء منتج، عدّل الملف من GitHub.

الحقول:
- `id`
- `n` اسم المنتج
- `p` السعر بالدينار العراقي
- `c` التصنيف
- `e` الإيموجي
- `active` إذا كانت `false` يختفي المنتج من الموقع.

## Telegram
إعداد استقبال الطلبات موجود في:
`data/store.json`

ضع اسم مستخدم بوت أو حساب استقبال الطلبات بدون @ في:
`telegramUsername`

الموقع لا يحتاج قاعدة بيانات أو سيرفر للطلبات: يجهز رسالة الطلب ويفتح محادثة Telegram، والزبون يضغط إرسال بنفسه.

تم التطوير بواسطة جعفر ماجد.
