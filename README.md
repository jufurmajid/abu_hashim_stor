# أبو هاشم للحوم والألبان والأجبان

متجر إلكتروني عربي بسيط ومتجاوب، مع بوت إدارة وبوت استقبال طلبات داخل نفس المشروع.

## المزايا
- عرض المنتجات والتصنيفات والبحث
- سلة مشتريات
- طلب كضيف
- إرسال الطلب مباشرة إلى بوت الطلبات في تيليجرام
- بوت إدارة لإضافة وتعديل وإخفاء وحذف المنتجات
- عربي RTL ومتوافق مع الموبايل
- API خلفي داخل نفس المشروع

## التشغيل
```bash
npm install
cp .env.example .env
npm start
```
ثم افتح `http://localhost:3000`.

## أوامر بوت الإدارة
`/start`
`/products`
`/add الاسم | السعر | التصنيف | الإيموجي`
`/edit ID | الاسم | السعر | التصنيف | الإيموجي`
`/hide ID`
`/show ID`
`/delete ID`

## الإعداد
ضع `ADMIN_BOT_TOKEN` و`ORDERS_BOT_TOKEN` و`ADMIN_CHAT_ID` في `.env`.

**لا تضع التوكنات داخل ملفات الواجهة.**

تم التطوير بواسطة جعفر ماجد
