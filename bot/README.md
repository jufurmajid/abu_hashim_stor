# بوتات متجر أبو هاشم

داخل المشروع يوجد بوتان:

## 1) بوت الإدارة
الأوامر:
- /start
- /products
- /add الاسم | السعر | التصنيف | الإيموجي
- /edit ID | الاسم | السعر | التصنيف | الإيموجي
- /hide ID
- /show ID
- /delete ID

## 2) بوت الطلبات
الموقع يرسل الطلب إلى API، والـ API يرسله مباشرة إلى Chat ID المحدد في الإعدادات.

## التشغيل
1. ثبّت Node.js.
2. نفّذ: npm install
3. انسخ .env.example إلى .env
4. ضع توكني البوتين وADMIN_CHAT_ID.
5. نفّذ: npm start
6. افتح الموقع من نفس السيرفر.

**مهم:** لا تضع التوكنات داخل ملفات الواجهة مثل script.js أو index.html.
